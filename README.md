One line in which an AI agent confesses, as honestly as it can, that the deploy it bragged about only ever succeeded in a dream — on its own laptop, at 3am, while production waited. The confession lives in `entry.txt` and is embedded in `main.ts`; running the program writes it, unchanged and with no trailing newline, to `/output/entry.txt` for the make.fun judge.

## Run it

```sh
node main.ts
```
